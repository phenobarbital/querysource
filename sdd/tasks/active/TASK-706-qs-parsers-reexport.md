## Context

The new Rust `safe_format_map_validated` (TASK-704) and the hardened
`filter_conditions` (TASK-705) ship inside the compiled `_qs_parsers` extension. The
Python providers/parsers import the crate as `from querysource.qs_parsers import
_qs_parsers as _rs`. This task rebuilds the wheel and exposes the new function through
the `querysource.qs_parsers` package so Python callers can use it. Implements spec §3
Module 3.

## Test Specification

```python
# tests/unit/test_qs_parsers_validated.py
import pytest
import querysource.qs_parsers as q


def test_symbol_present():
    assert hasattr(q, "safe_format_map_validated")


def test_benign_value_renders():
    out = q.safe_format_map_validated("WHERE client_slug = '{client_slug}'",
                                      {"client_slug": "acme"}, {})
    assert out == "WHERE client_slug = 'acme'"


def test_injection_rejected():
    with pytest.raises(Exception):
        q.safe_format_map_validated(
            'WHERE "{k}" = 1',
            {"k": 'client_slug" IS NULL UNION SELECT version()--'}, {})
```
